# Reza

ИИ-администратор для мастеров и малого бизнеса и каталог, где клиенты находят мастеров и записываются.

- **Мастер** регистрируется, указывает услуги, цены и часы работы. Получает ссылку на своего Telegram-бота и страницу в каталоге.
- **Клиент** пишет в Telegram или записывается на странице мастера. ИИ отвечает за мастера, записывает в свободное время, создаёт заявки и передаёт мастеру сложные вопросы.
- **Мастер** видит всё в кабинете, может перехватить любой диалог и получает уведомления в Telegram.
- Интерфейс на русском, французском и немецком.

## Что внутри

| Часть | Где |
|---|---|
| Сервер (Node.js, Hono) | `src/server.js` |
| База данных (Postgres) | `src/db.js` |
| Вход, пароли, сессии | `src/auth.js` |
| ИИ (Claude API) | `src/ai.js`, правила для ИИ — `src/logic.js` |
| Telegram-бот | `src/telegram.js` |
| Интерфейс (кабинет, каталог, сайт) | `web/app.html` (+ `web/server-mode.js`), собирается в `public/index.html` |
| Тесты | `test/api.test.js` |

Один общий бот Reza обслуживает всех мастеров: у каждого мастера своя ссылка `t.me/<бот>?start=<адрес-мастера>`. Личный Telegram мастера бот не трогает, поэтому ИИ никогда не ответит друзьям и семье.

## Запуск в интернете (≈30 минут, бесплатно для начала)

Понадобятся 4 бесплатных аккаунта.

1. **Telegram-бот.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя, например `Reza Lyon`, и адрес, например `reza_lyon_bot`. Сохраните **токен**.
2. **Ключ Claude API.** [console.anthropic.com](https://console.anthropic.com) → Settings → API Keys → Create Key. Пополните баланс (для начала хватит 5–10 $). Сохраните **ключ**.
3. **База данных.** [neon.tech](https://neon.tech) → New Project → скопируйте **Connection string** (начинается с `postgresql://`).
4. **Хостинг.** [render.com](https://render.com) → войдите через GitHub → **New → Blueprint** → выберите этот репозиторий. Render прочитает `render.yaml` и попросит заполнить:
   - `DATABASE_URL` — строка из Neon;
   - `ANTHROPIC_API_KEY` — ключ Claude;
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `PUBLIC_URL` — адрес сервиса на Render, например `https://reza.onrender.com` (виден после первого запуска; впишите его и нажмите **Manual Deploy**).
   `SESSION_SECRET` и `CRON_SECRET` Render создаст сам.
5. **Напоминания клиентам.** На [cron-job.org](https://cron-job.org) создайте задачу «каждый час» на адрес
   `https://<ваш-адрес>/api/cron/reminders?key=<CRON_SECRET>` (значение `CRON_SECRET` — в настройках сервиса на Render).

Проверка: откройте ваш адрес → «Для мастеров» → «Создать» → зарегистрируйтесь → **Интеграции** → «Подключить уведомления» → отправьте клиентскую ссылку себе в Telegram и напишите боту как клиент.

> На бесплатном тарифе Render сервер «засыпает» через 15 минут без запросов, и первый ответ после сна приходит через ~30–60 секунд. Когда появятся первые платящие мастера, переключите сервис на тариф Starter (7 $ в месяц).

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Без `DATABASE_URL` используется локальная база в папке `.data`. Без `ANTHROPIC_API_KEY` ИИ не отвечает, и сообщения клиентов передаются мастеру.

```bash
npm test
```

## Стоимость ИИ

По умолчанию ответы пишет `claude-opus-5-5` с низким уровнем рассуждений (`REZA_EFFORT=low`). Модель и уровень меняются переменными `REZA_MODEL` и `REZA_EFFORT` без правки кода. Расход виден в консоли Anthropic в разделе Usage.
